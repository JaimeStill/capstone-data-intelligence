# capstone-data-intelligence

The integration root of the data-intelligence capstone: the compose stack of NATS, PostgreSQL with
pgvector, and SeaweedFS that Bunrei and Mikoshi run against, along with Torii; the contracts the
two services build against; the acceptance run over docs-corpus v0.2.0; the demo dataset; and the
presentation. Its working context is [`context/README.md`](context/README.md), and the stack's
services, ports, and tasks are in [`context/stack.md`](context/stack.md).
