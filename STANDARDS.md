# capstone-data-intelligence standards

The judgement calls the standards-reviewer applies to capstone-data-intelligence, beyond what
`mise run check` enforces. Each is one line; the architecture pages hold the reasoning.

- A contract note (`chunks`, `protocol`, `events`) states what both services rely on and nothing either keeps to itself; a change to one names every task it reaches.
- `architecture/principles/context-architecture.md`: the README, `context/`, and `docs/`.
- `architecture/principles/comments.md`: every comment in the stack's files and scripts.
