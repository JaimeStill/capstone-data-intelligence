# capstone-data-intelligence context

The integration root of capstone.data-intelligence: the contracts Bunrei and Mikoshi build against
side by side, the compose stack, the demo dataset arranged as a context tree, the acceptance run
over docs-corpus v0.2.0 measured against its baseline, and the live presentation that walks the
signal flow layer by layer and argues for an elemental architecture.

The capstone's architecture, scope, and blocking points are `standards-lab/context/data-intelligence.md`,
and its design detail `standards-lab/docs/data-intelligence.md`; this repository takes their
working detail in as its tasks settle it. Its goals live in the coordinator's roadmap:
`capstone.data-intelligence.foundation` now, whose record is
[`goals/capstone.data-intelligence.foundation.md`](goals/capstone.data-intelligence.foundation.md),
then `capstone.data-intelligence.showcase`.
